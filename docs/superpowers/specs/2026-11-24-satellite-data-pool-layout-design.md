# 卫星遥感数据资源池管理页面布局设计

## 目标

移除数据资源池页面顶部三个统计卡片和资源池列表表格的页面展示；保留资源池创建、导入、详情、监控及接口逻辑。三个统计卡片在收起状态下同时展示饼图与分类明细（名称、数量、占比），展开状态继续展示现有趋势图和数据列表。

## 约束与非目标

- 只修改 `SatelliteDataPoolLayout.vue` 的页面模板与样式。
- 不删除资源池 API、数据加载、创建、导入、详情、监控、删除等方法。
- 不改变三个卡片的展开/收起、周期切换、趋势图、数据列表筛选行为。
- 删除“页面展示”不等于删除资源池数据模型或后端能力。

## 实现方案

采用最小改动方案：移除统计卡片和列表表格的模板块；调整收起状态 CSS，使 `.access-data-content` 横向容纳饼图与 `.access-detail-list`，并在窄屏下允许换行/纵向排列。三个卡片复用已有分类数组，不新增接口。

## 验收标准

页面不显示顶部统计卡片和资源池列表；三个卡片收起时显示饼图及分类明细，展开时趋势图和数据列表仍可用；项目构建通过。
